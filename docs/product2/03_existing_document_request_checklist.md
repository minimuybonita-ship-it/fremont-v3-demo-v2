# Existing Document Request Checklist
What to request from a new organization before configuration begins.

- [ ] Code of conduct
- [ ] Social media / communications policy
- [ ] Weather / severe-weather policy
- [ ] MPR (multi-purpose room / mandatory playing rules) explanation
- [ ] Lice / health protocol documents, if any
- [ ] Concussion and hydration information
- [ ] Volunteer agreement
- [ ] Fundraising agreement
- [ ] Equipment agreement
- [ ] Financial assistance process documents — **do not import these into the Command Center.** Per V3 §24, financial-assistance applications, hardship letters, pay stubs, tax returns, and government-assistance documentation stay in the organization's existing restricted process. The Command Center may receive an authorized adjustment (e.g. "+3 hours") after a decision, never the underlying documents or reason.
- [ ] Current season calendar (games, practices, events)
- [ ] Current registration form/fields (to map against the Family & Athlete Hub's fields)
