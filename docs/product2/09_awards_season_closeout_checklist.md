# Awards / Season Closeout Checklist

- [ ] Final volunteer-hour reconciliation per family (completed vs. required, any unresolved `needs_review` rows closed out one way or another)
- [ ] Final fundraising reconciliation per family (cash + credit vs. goal)
- [ ] Unresolved no-show fees resolved or explicitly waived (recorded, not silently dropped)
- [ ] Uniform return/handoff tracked where applicable
- [ ] Season status set to `closed`
- [ ] Final Board Report generated (template 06) for the full season
- [ ] Awards Night logistics — **note:** the QR-code/digital-book/POD flow described in the architecture is future/premium and not part of this checklist until that module is built. Awards Night itself (names, order, recognition) is an organization-run event outside the Command Center's current scope.
