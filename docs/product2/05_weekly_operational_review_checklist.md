# Weekly Operational Review Checklist
For the Volunteer Coordinator / Commissioner, run every week during active season.

- [ ] Review Commissioner Cockpit exceptions feed — resolve or explicitly defer each one
- [ ] Confirm staffing for this week's game(s): filled vs. needed, any shortages
- [ ] Review open replacement-pool shifts — any stuck unclaimed?
- [ ] Review completed-but-unverified assignments — verify or flag `needs_review`
- [ ] Review pending social-share submissions
- [ ] Review families below their fundraising goal (informational, not punitive framing)
- [ ] Check for any `needs_review` assignments older than 7 days
- [ ] Confirm next week's job instances exist (created from template) if games are scheduled
