# Registration Launch Checklist

- [ ] Season row created with correct start/end dates
- [ ] `season_config` row created with the organization's confirmed values (not left at Fremont defaults unless that's their actual choice)
- [ ] Divisions and teams created
- [ ] Job role matrix entered (from Workbook Tab 2)
- [ ] Standard Home Game template built (from Workbook Tab 3)
- [ ] Training resources entered for any role requiring them; anything undocumented marked `ffl_to_confirm` rather than invented
- [ ] Registration link tested end-to-end as a family would use it (not just as an admin)
- [ ] Confirm families enter their own information — the board/coordinator should not be manually transcribing every family's data
- [ ] Commissioner and Team Parent `app_role` rows created and access-tested
- [ ] Communication preferences captured per family
